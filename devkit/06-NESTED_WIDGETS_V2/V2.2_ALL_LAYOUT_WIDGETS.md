## 📊 Nesting Rules

### ✅ Allowed
- **Multi → Multi**: Container can hold Row, Row can hold Stack, etc.
- **Single → Multi**: Text can go into Container, Button can go into Column, etc.

### ❌ Not Allowed
- **Any → Single**: Nothing can go into Text, Button, or Image
- **Widget → Self**: Widget cannot be its own parent (circular)
- **Parent → Descendant**: Container cannot be dropped into its own child

## 🔍 Container Detection Logic

**File**: `frontend/lib/core/models/page.dart`

```dart
static bool _isContainerType(String type) {
  const containerTypes = [
    'Container',
    'Card',
    'Row',         // ✅ Already included
    'Column',      // ✅ Already included
    'Stack',       // ✅ Already included
    'ListView',    // ✅ Already included
    'GridView',    // ✅ Already included
  ];
  return containerTypes.contains(type);
}
```

**Logic**: 
- When widget is created, `isContainer` is automatically set based on type
- Frontend and backend both check `isContainer` boolean
- Green "CONTAINER" badge shows in widget library
