**Implemented handler:**
```dart
void _onUpdateRemoteSelection(
  UpdateRemoteSelection event,
  Emitter<PageState> emit,
) {
  try {
    final selectionEvent = event.selectionEvent as PageSelectionEvent;
    
    // Update other users' selections map
    final updatedSelections = Map<String, String?>.from(state.otherUsersSelections);
    
    if (selectionEvent.widgetId == null) {
      // Remove selection if widgetId is null
      updatedSelections.remove(selectionEvent.userId);
    } else {
      // Update selection
      updatedSelections[selectionEvent.userId] = selectionEvent.widgetId;
    }

    emit(state.copyWith(otherUsersSelections: updatedSelections));
    
    print('✨ Updated selection for user ${selectionEvent.userId}: ${selectionEvent.widgetId}');
  } catch (e, stack) {
    print('❌ Error updating remote selection: $e');
    print(stack);
  }
}
```

## How It Works

### Selection Flow:

1. **User A selects a widget:**
   - Frontend calls `SelectPageWidget` event
   - PageBloc emits new state with `selectedWidgetId`
   - PageBloc sends selection to WebSocket: `_wsClient.sendSelection()`
   - Widget shows **blue border** (own selection)

2. **Backend receives selection:**
   - `page:selection` event received
   - Backend broadcasts to other users: `page:selection:updated`

3. **User B receives selection:**
   - Frontend WebSocket receives `page:selection:updated`
   - Emits `UpdateRemoteSelection` event
   - PageBloc updates `otherUsersSelections` map
   - Widget shows **orange border** (other user's selection)

4. **User A deselects (clicks canvas):**
   - Sends `widgetId: null`
   - User B's orange border removed

## Visual Indicators

### Border Colors:
- **Blue (2.5px solid):** Your own selection
- **Orange (2.5px solid):** Another user's selection
- **Green (2px solid):** Hover state when dragging
- **No border:** Not selected

### Priority:
1. Own selection (blue) - highest priority
2. Other user selection (orange)
3. Hover state (green)
4. No border

## Use Cases

### Scenario 1: Collaborative Editing
1. User A and User B open same page
2. User A clicks on Container widget
3. User A sees blue border
4. User B sees orange border on same widget
5. Both users know which widget is being edited

### Scenario 2: Multiple Selections
1. User A selects Widget 1 (blue on A, orange on B)
2. User B selects Widget 2 (blue on B, orange on A)
3. Each user sees their selection in blue
4. Each user sees other's selection in orange

### Scenario 3: Selection Cleared
1. User A selects Widget 1
2. User B sees orange border
3. User A clicks canvas (deselects)
4. Orange border disappears for User B
