# V2.6: Auto-Layout Changes

## 🎯 Goals
1. Container/Card/Column → Use Flutter Column widget (auto-arrange vertically)
2. Row → Use Flutter Row widget (auto-arrange horizontally)
3. Stack → Keep manual positioning with Positioned
4. Update sizes: Canvas 2000x2000, multi-widgets 400x150, singles vary

---

## ✅ Changes Made

### 1. Canvas Size: 2000x2000
**File**: `frontend/lib/core/models/page.dart`

- Changed fromJson defaults: same

### 2. Default Container Size: 400x150
**File**: `frontend/lib/features/page/bloc/page_bloc.dart`

### 4. Auto-Layout Rendering
**File**: `frontend/lib/features/page/views/page_canvas_view.dart`

Need to replace rendering logic in `_buildWidgetContent` method:

#### Container, Card, Column (Vertical Auto-Layout)
```dart
} else if (widget.type == 'Container' || widget.type == 'Card' || widget.type == 'Column') {
  if (children.isEmpty) {
    // Show placeholder
  } else {
    // Use Flutter Column widget - auto-arrange vertically
    content = Padding(
      padding: const EdgeInsets.all(8.0),
      child: Column(
        mainAxisAlignment: MainAxisAlignment.start,
        crossAxisAlignment: CrossAxisAlignment.start,
        mainAxisSize: MainAxisSize.min,
        children: renderedChildren.map((child) {
          return Padding(
            padding: const EdgeInsets.only(bottom: 8.0),
            child: child,
          );
        }).toList(),
      ),
    );
  }
}
```

#### Row (Horizontal Auto-Layout)
```dart
} else if (widget.type == 'Row') {
  if (children.isEmpty) {
    // Show placeholder
  } else {
    // Use Flutter Row widget - auto-arrange horizontally
    content = Padding(
      padding: const EdgeInsets.all(8.0),
      child: Row(
        mainAxisAlignment: MainAxisAlignment.start,
        crossAxisAlignment: CrossAxisAlignment.start,
        mainAxisSize: MainAxisSize.min,
        children: renderedChildren.map((child) {
          return Padding(
            padding: const EdgeInsets.only(right: 8.0),
            child: child,
          );
        }).toList(),
      ),
    );
  }
}
```

#### Stack (Manual Positioning - Keep As-Is)
```dart
} else if (widget.type == 'Stack') {
  if (children.isEmpty) {
    // Show placeholder
  } else {
    // Keep Stack with Positioned children (manual layout)
    content = Stack(
      clipBehavior: Clip.none,
      children: renderedChildren.map((child) {
        final index = renderedChildren.indexOf(child);
        final childWidget = children[index];
        
        return Positioned(
          left: childWidget.position.dx,
          top: childWidget.position.dy,
          child: child,
        );
      }).toList(),
    );
  }
}
```

## ⚠️ Breaking Changes

1. **Position fields ignored** for Container/Card/Column/Row children
2. **Only Stack** uses position.dx and position.dy now
3. **Drop handlers** don't need to calculate positions for auto-layout widgets
