## 🎨 All Multi-Widgets Accept Children

### Container Type Detection

All 5 multi-widgets are configured as containers:

```dart
static bool _isContainerType(String type) {
  const containerTypes = [
    'Container',  // ✅
    'Card',       // ✅
    'Row',        // ✅
    'Column',     // ✅
    'Stack',      // ✅
  ];
  return containerTypes.contains(type);
}
```

### Rendering Logic

All multi-widgets use the same drop logic:

```dart
if (widget.isContainer) {  // True for all 5 types
  return DragTarget<Object>(
    onWillAccept: (draggedData) {
      // Accepts Map<String, dynamic> from library
      if (draggedData is Map<String, dynamic>) return true;
      
      // Accepts PageWidget for moving
      if (draggedData is PageWidget) {
        return WidgetTreeHelper.canDropInto(...);
      }
      
      return false;
    },
    onAccept: (draggedData) {
      if (draggedData is Map<String, dynamic>) {
        _handleLibraryDrop(...);  // Create new widget
      } else if (draggedData is PageWidget) {
        _handleNestedDrop(...);   // Move existing widget
      }
    },
    ...
  );
}
```

## 📐 Drop Behavior Summary

### Library Drops → Multi-Widgets
- **Source**: Widget Library (Map<String, dynamic>)
- **Target**: Any multi-widget (Container, Card, Row, Column, Stack)
- **Handler**: `_handleLibraryDrop()`
- **Result**: New PageWidget created with parentId
- **Position**: Calculated (column layout: 20px left, vertical with 16px spacing)

### Widget Moves → Multi-Widgets
- **Source**: Existing widget on canvas (PageWidget)
- **Target**: Any multi-widget (Container, Card, Row, Column, Stack)
- **Handler**: `_handleNestedDrop()`
- **Result**: Widget parentId updated to new container
- **Position**: Calculated (column layout: 20px left, vertical with 16px spacing)
