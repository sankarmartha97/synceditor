# V2.13: Drop Anywhere on Widget

## Summary
Fixed the issue where users could only drop widgets in empty areas of containers. Now you can drop widgets anywhere on a container widget, even directly on top of existing children.

## Problem
Previously, when dragging a widget over a container:
- ❌ Could drop in empty areas of the container
- ❌ Could NOT drop when hovering over existing child widgets
- ❌ Child widgets blocked the drop events
- ❌ Had to find specific empty spots to drop

This made it difficult to add widgets to containers that already had children, especially when children filled most of the container space.

## Root Cause
- Child widgets were rendered on top of the DragTarget
- Child widgets intercepted pointer events
- DragTarget never received the drop event when hovering over children
- Only empty areas of the container could accept drops

## Solution
Added `IgnorePointer` wrapper around the children when hovering:
- When dragging over container: `IgnorePointer(ignoring: true)` on children
- Children become transparent to pointer events during drag
- DragTarget can receive drop events anywhere on container
- Normal pointer events resume after drop completes

## Changes Made

### Frontend Changes

#### `frontend/lib/features/page/views/page_canvas_view.dart`

**Before:**
```dart
child: Stack(
  children: [
    // Children block drop events
    _buildWidgetContent(
      widget,
      false,
      isSelected,
      children,
      allWidgets,
    ),
    
    if (isHovering)
      Positioned.fill(
        child: Container(/* Drop indicator */),
      ),
  ],
),
```

**After:**
```dart
child: Stack(
  children: [
    // ✨ NEW: Ignore pointer events on children when hovering
    IgnorePointer(
      ignoring: isHovering,  // Disable children's pointer events during drag
      child: _buildWidgetContent(
        widget,
        false,
        isSelected,
        children,
        allWidgets,
      ),
    ),
    
    if (isHovering)
      Positioned.fill(
        child: IgnorePointer(  // ✨ NEW: Drop indicator also ignores pointers
          child: Container(/* Drop indicator */),
        ),
      ),
  ],
),
```

## Technical Details

### IgnorePointer Behavior:
- `ignoring: true`: Widget doesn't respond to pointer events
- `ignoring: false`: Widget responds normally to pointer events
- Affects entire widget tree below it
- Visual appearance unchanged

### When Is It Applied?
```dart
final isHovering = candidateData.isNotEmpty;
```
- `isHovering = true`: When widget being dragged is over this container
- `isHovering = false`: When not dragging or dragging elsewhere

### Performance:
- No performance impact
- Only affects pointer event handling
- No visual re-rendering
- Instant toggle on/off

### Side Effects:
- During drag: Can't click/select children (intended behavior)
- After drop: Everything works normally
- Dragging children out still works (they have their own Draggable)
