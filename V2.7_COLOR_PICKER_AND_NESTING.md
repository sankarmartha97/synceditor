### 2. Nested Multi-Widget Support (Already Implemented ✅)

**Logic**: `frontend/lib/core/utils/widget_tree_helper.dart`

```dart
static bool canDropInto(
  PageWidget draggedWidget,
  PageWidget targetWidget,
  List<PageWidget> allWidgets,
) {
  // Cannot drop into self
  if (draggedWidget.id == targetWidget.id) return false;

  // Target must be a container
  if (!targetWidget.isContainer) return false;

  // Cannot drop a parent into its own descendant (circular reference)
  final descendants = getDescendants(draggedWidget.id, allWidgets);
  if (descendants.any((w) => w.id == targetWidget.id)) {
    return false;
  }

  return true; // ✅ NO type restrictions!
}
```

**Container Types**: `frontend/lib/core/models/page.dart`

```dart
static bool _isContainerType(String type) {
  const containerTypes = [
    'Container',
    'Card',
    'Row',
    'Column',
    'Stack',
  ];
  return containerTypes.contains(type);
}
```

## 📐 Nesting Rules

### What CAN Drop Into Multi-Widgets

| Target Widget | Can Accept | Examples |
|---------------|-----------|----------|
| **Container** | ✅ All widgets | Text, Button, Image, Container, Card, Row, Column, Stack |
| **Card** | ✅ All widgets | Text, Button, Image, Container, Card, Row, Column, Stack |
| **Row** | ✅ All widgets | Text, Button, Image, Container, Card, Row, Column, Stack |
| **Column** | ✅ All widgets | Text, Button, Image, Container, Card, Row, Column, Stack |
| **Stack** | ✅ All widgets | Text, Button, Image, Container, Card, Row, Column, Stack |

### What CANNOT Drop

1. ❌ **Self-drop**: Widget cannot drop into itself
2. ❌ **Circular reference**: Parent cannot drop into its own descendant
   - Example: If Container A contains Card B, Card B cannot accept Container A

### Valid Nested Examples

**1. Multi-Widget Inside Multi-Widget**:
```
Container
└─ Row (multi-widget inside multi-widget) ✅
   ├─ Button
   └─ Text
```

**2. Deep Nesting**:
```
Container
└─ Card
   └─ Column
      └─ Row
         ├─ Button
         └─ Text
```

**3. Same Type Nesting**:
```
Container
└─ Container (same type nesting) ✅
   └─ Text
```

**4. Complex Layouts**:
```
Row
├─ Container ✅
│  ├─ Text
│  └─ Button
├─ Column ✅
│  ├─ Image
│  └─ Text
└─ Stack ✅
   ├─ Image
   └─ Button (overlay)
```
